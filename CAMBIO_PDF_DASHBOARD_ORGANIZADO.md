# Cambio: PDF individual del dashboard organizado

Se reorganizo la presentacion del informe individual exportado desde el dashboard institucional:

- Encabezado institucional con banda superior.
- Bloques separados para datos del estudiante y datos del intento.
- Panel independiente de seguridad del simulacro.
- Tarjetas de indicadores alineadas y sin superposiciones.
- Resumen del intento en cuadricula.
- Grafico general con escala 0% a 100%.
- Resultado por area con barras limpias.
- Recomendacion pedagogica en bloque final.
- Correccion visual del tiempo empleado cuando llega desde Sheets como fecha base 1899-12-30.
