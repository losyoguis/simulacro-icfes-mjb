# Cambio aplicado: botones de sincronización y envío externo desactivados

Se eliminaron de la pantalla de resultados los botones:

- Sincronizar con Sheets
- Enviar Informe al MJB

La app conserva el flujo principal del simulacro, el informe PDF y el envío único del informe PDF configurado previamente.

También se agregó una regla CSS de respaldo para mantener ocultos esos controles si existiera caché del navegador.
